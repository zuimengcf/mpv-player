## 🌐 mpvEx Web

这是 **mpvExtended** 的官方 Next.js 网站 —— 一个基于 mpv 构建的强大 Android 视频播放器。网站展示功能、提供下载，并作为项目的线上门户。

### 🚀 快速开始

```bash
# 开发
pnpm dev           # 启动开发服务器
pnpm dev:debug     # 以调试模式启动

# 依赖图表
pnpm analyze       # 分析依赖

# 构建
pnpm build         # 生产构建
pnpm start         # 启动生产服务器
pnpm start:prod    # 在 3000 端口启动

# 代码质量
pnpm lint          # 运行 linter
pnpm lint:fix      # 自动修复 lint 问题
pnpm format        # 格式化代码
pnpm type-check    # TypeScript 类型检查

# 维护
pnpm clean         # 清理构建产物
pnpm reinstall     # 完整重装

```

## 📦 项目结构

- 框架：Next.js 16.1.5 + React 19.2.4
- 样式：Tailwind CSS 4.1.18 + Material Design
- 语言：TypeScript
- Lint：Biome（格式化与 lint）
- 图标：Lucide React 与自定义图标


## 🎯 功能特性

- 现代技术栈：基于 Next.js 16、React 19 与 TypeScript 构建
- 响应式设计：Tailwind CSS 遵循 Material Design 原则
- 性能优化：自动化代码分割与优化
- 类型安全：全量 TypeScript 覆盖与严格类型检查
- 代码质量：Biome 提供一致的代码格式与 lint
